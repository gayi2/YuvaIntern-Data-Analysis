# YuvaIntern NSDC – Data Analysis Internship

## Project Overview

This repository contains the work completed during my YuvaIntern
internship under NSDC, focusing on data analysis and visualization
using R.

The project uses the publicly available Most Streamed Spotify Songs
2025 dataset.

## Technologies Used

- R
- RStudio / Posit Cloud
- tidyverse
- ggplot2
- corrplot
- Data Visualization
- Exploratory Data Analysis

## Week 1 – Data Cleaning and Preliminary Analysis

The Week 1 task focused on:

- Dataset importing
- Dataset structure inspection
- Missing-value detection
- Duplicate checking
- Outlier detection
- Data normalization
- Categorical variable encoding
- Descriptive statistics
- Preliminary correlation analysis

### Key Finding

A correlation of 0.7795761 was observed between daily Spotify
streams and total Spotify streams, indicating a strong positive
relationship.

## Week 2 – Data Visualization and Insight Communication

The Week 2 task focused on communicating insights through
visualizations.

Visualizations created include:

- Top 10 Most Streamed Songs
- Top 10 Artists by Number of Songs
- Distribution of Daily Streams
- Daily Streams vs Total Spotify Streams
- Collaboration vs Non-Collaboration Songs
- Top Artists by Total Spotify Streams
- Top Songs by Daily Stream Share
- Correlation Heatmap
